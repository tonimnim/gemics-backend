# Ozone logo

The mark stands in for the "o" of "ozone". The letters "zone" (Outfit Bold,
outlined) are set at 84% of its height and centred on it, because a round,
open mark looks smaller than flat-topped letters of the same height. The mark
keeps the font's own "o" spacing and is the same colour as the letters. No font is
needed to print it. Outfit is under the SIL Open Font License (`Outfit-OFL.txt`).

| File | Use |
|---|---|
| `ozone-logo.svg` / `.pdf` / `.png` | Indigo `#5B5BD6`. Light shirts and screens. |
| `ozone-logo-on-dark.*` | Light indigo `#7C7CF0`. Dark shirts and the website. |
| `ozone-logo-black.*` | Black. |
| `ozone-logo-white.*` | White. Dark shirts. |
| `ozone-logo-current.svg` | `currentColor`, for the website and dashboard. |
| `ozone-mark.svg` | The mark alone (sleeve, back neck, favicon). |

- **For the printer:** SVG and PDF are vector and scale to any size. PNGs are
  6000 px wide with a transparent background, about 50 cm at 300 dpi.
- **Size:** the artwork is 229 × 55 mm, including a thin transparent margin.
  Keep at least the height of the "z" clear around it.
- **Colours:**

  | Name | Hex |
  |---|---|
  | Indigo | `#5B5BD6` |
  | Light indigo | `#7C7CF0` |
  | White | `#FFFFFF` |
  | Black | `#000000` |

- **The mark:** it is the original traced mark with its straight-segment
  facets smoothed into curves for print. The shape is unchanged.
